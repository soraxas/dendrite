## ADDED Requirements

### Requirement: Keyboard access

Every interactive element of the UI (links, buttons, selectable rows, tabs) SHALL be reachable with Tab, show a visible focus indicator, and activate with Enter (and Space for buttons and rows).

#### Scenario: Open an experiment from the keyboard

- **WHEN** a keyboard user tabs to a "reused from" link in the step panel and presses Enter
- **THEN** that experiment opens, as a click would
